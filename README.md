# 弹核球 NEON PINBALL v4

![游戏界面](assets/images/playing.gif)

弹核球是一款霓虹风格的弹珠生存射击游戏。玩家操控发光弹球在网格场地中移动射击，利用撞墙反弹、冲刺撞人和过载爆发消灭不断涌来的敌人，每五波迎战一只 BOSS，越往后规模越强。

游戏中的卡牌与 BOSS 均取自 Astrbot 群友，包括吾二、喵雅喵、喵斯喵与首只 BOSS 喵叶喵、枣子ᶜᵒˡˡᵃᵖˢᵃʳ、薰衣霓等。角色技能取自群聊日常，例如喵叶喵只戳不发言、口头禅是撅，形成独特的群友梗图鉴。

操作采用 WASD 移动、J 射击、K 冲刺、H 修复、空格过载，支持触屏横屏。升级三选一强化卡，含五十一张常规卡与常驻技能，另有冲刺充能、撞人减 CD 等机制，玩家可自由组合射击与冲刺流派。

代码使用 PixiJS v8 渲染，预烘焙发光贴图保证性能。
